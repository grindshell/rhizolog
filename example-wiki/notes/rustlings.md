# Rustlings

This page is here to *not* match something.

Its slug starts with `notes/rust`, and it is not under [[notes/rust]]. The
prefix filter compares path segments rather than characters, so it stops at the
separator: `notes/rust` names a directory and `notes/rustl` names nothing at
all.

Worth having as a page rather than only as a test, because character-wise
matching works right up until the day somebody files `notes/rust-2024` beside
this and wonders why it turned up in the wrong listing.
